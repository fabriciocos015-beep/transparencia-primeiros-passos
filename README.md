# transparencia-primeiros-passos

Analyze public expenditures based on data from the Brazilian Transparency Portal.

## What it does? 

It answer three questions: 

- Question 1 — Top 10 órgãos by amount paid
- Question 2 — Total paid per expense group
- Question 3 — Duplicate rows:

## data source + download link

- Data source = Portal da Transparência (Dados Abertos)
- Link = https://portaldatransparencia.gov.br/download-de-dados/despesas-execucao
- Suggested inputs → year = 2026; month = august

## how to run

- Download the CSV file from the specified source.
- Execute the notebook "analise.ipynb". 
- Make sure all the file are in the same repository.
